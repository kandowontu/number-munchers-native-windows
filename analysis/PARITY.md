# Number Munchers parity ledger

This is the completion gate for the native port. The current build is **not a 1:1 port**. A row is only marked `verified` when native behavior has been compared with a recorded run of the supplied DOS build; having a plausible native implementation is not enough.

Word Munchers has its own independent completion matrix in
[`WORD-PARITY.md`](WORD-PARITY.md). The shared goal cannot close until both
ledgers satisfy their completion rules.

Status meanings:

- `verified` — reference evidence and an automated or repeatable native check agree.
- `partial` — implemented, but materially different or not fully measured.
- `missing` — original behavior is absent.
- `substitute` — native code deliberately stands in for an original subsystem and is not parity.
