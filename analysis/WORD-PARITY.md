# Word Munchers parity ledger

This is the independent completion gate for the Word Munchers half of the
native port. The current Word runtime is **not a 1:1 port**. The supplied Word
executable has been audited statically and the native runtime is extensively
headless-tested. Muted live evidence now covers startup/title/instructions,
all Information pages, four-direction player movement, a complete chew,
rightward Reggie movement, the full 21-tick collision bite, both feedback
kinds, name entry, admitted Hall, replay, and nineteen Options/Hall-family
states. A second organic user run adds a complete board, target exemplar,
pause/quit, downward movement, safe-zone changes, warning, and top-edge Reggie
entry. Lossless live evidence now also covers all six scripted cartoons.
Remaining presentation variants, autonomous attract coverage, an organically
completed live board source for the now-measured cartoon Wipe, physical input,
broader CGA gameplay/UI coverage, and physical audio remain incomplete.
Static/native hashes outside captured slices are not presented as live
original hashes.

Status meanings match `PARITY.md`: `verified` requires authoritative source
evidence plus an automated or repeatable native check; `partial` means that a
material implementation or verification boundary remains; `missing` means the
original behavior is absent; and `substitute` identifies an intentional native
stand-in.

## Completion rule

Word Munchers must not be called 1:1 and the shared goal must not be marked
complete while any material row above is `partial`, `missing`, or `substitute`,
unless the user explicitly accepts that row as an intentional deviation. A
final package must rerun all console gates and the isolated-production audit,
then agree with whatever live/physical reference evidence closes the remaining
rows.
